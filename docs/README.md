# Documentación histórica

Estos documentos registran el diseño, las pruebas y las mediciones de la app
durante su desarrollo. Se conservan como referencia, no como documentación
operativa del ejemplo público.

Algunos textos mencionan el modelo privado de 127 tablas y
`docs/MODULOS_PROPUESTOS.json`, que no se distribuye. El registro de sesiones
`agents.mb` se conserva en la raíz del repositorio. El ejemplo público actual es
`examples/demo-150-mysql.sql`; las cifras de `performance/` corresponden al
modelo privado y no son reproducibles solo con ese ejemplo.
